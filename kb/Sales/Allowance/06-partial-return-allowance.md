# 部分退貨與折讓處理

客戶僅退回部分商品或服務時，不應將整張發票直接作廢。應依實際退貨內容建立折讓，保留原始銷售與後續異動軌跡。

## 處理流程

1. 核對原訂單與原發票。
2. 確認實際退貨品項、數量與金額。
3. 建立退貨或退款紀錄。
4. 依退貨結果建立對應折讓單。
5. 檢查折讓金額與原發票剩餘金額。
6. 將折讓結果同步至訂單、退款與會計資料。

自動串接情境應避免人工再次建立相同折讓，防止重複折讓或金額超出原交易。
