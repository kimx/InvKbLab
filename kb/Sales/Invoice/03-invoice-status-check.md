# 發票狀態查詢與對帳

發票開立後，應區分系統內的開立結果與財政部平台的傳輸狀態，不能只以單次 API 回應判斷整筆交易已完成。

## 查核原則

1. 保存發票號碼、交易識別資料與開立時間。
2. 查詢目前發票狀態及上傳結果。
3. 將訂單、付款與發票資料進行對帳。
4. 若狀態長時間不同步，依異常處理 SOP 進一步確認。
5. 保留查詢條件與回應結果，供後續稽核。

發生逾時或未知結果時，應先查詢原交易狀態，再決定是否重送，避免重複開立發票。
